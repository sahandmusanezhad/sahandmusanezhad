# Working in this repository

This is Sahand's GitHub profile: `README.md`, the SVGs in `assets/`, and the
*Profile assets* workflow that rebuilds the stats card and the snake on the
`output` branch.

## Every task ends in a merged pull request

The owner wants each change to land as a pull request he opened and merged,
so that every one counts on his profile. Never push straight to `main`:

1. Commit on a branch.
2. Push it and open a pull request into `main` that says what changed and why.
3. Merge it with a merge commit (not squash or rebase) once any checks pass.
4. After the merge, confirm the *Profile assets* run on `main` succeeded.

The `finish-with-pr` skill has the exact steps. Reply to the owner in Persian.
